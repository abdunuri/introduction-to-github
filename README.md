# Introduction to GitHub

This repository is a GitHub Skills training repository for learning the basics of GitHub.

## Main Concept

The repo is not a custom application. It is course material that introduces new developers to the core GitHub workflow: repositories, branches, commits, pull requests, and merges.

## What It Teaches

- How repositories organize project work
- How branches isolate changes
- How commits save progress
- How pull requests support review and collaboration
- How merging brings approved changes into the main branch

## Intended Audience

- New GitHub users
- Students
- Beginner developers
- Anyone learning the basic contribution workflow

## Status

This repo is useful as a learning artifact and reference for GitHub onboarding.
